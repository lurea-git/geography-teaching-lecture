使用说明

本模板适用于“指定课题、无学生现场说课”的常见面试形式。它不是固定逐字稿，而是一套可替换的表达骨架：将方括号中的内容换成具体课题信息，再根据实际课型删减即可。

说课不是把课堂重新“演”一遍，而是向评委说明四件事：为什么这样教、准备教什么、学生怎样学、如何证明学生学会了。高级职称面试还应体现教师对课程标准、学科育人价值、学生思维发展和教学改进的理解。

建议实际口述控制在13分30秒—14分30秒。全文不必逐字背诵，重点记住“课标—学情—目标—问题链—证据—迁移—反思”七个锚点。

一条记忆主线

真实情境 → 核心问题 → 证据分析 → 机制解释 → 迁移应用 → 评价反馈

一、开场：报题与教学主张（约30秒）

尊敬的各位评委老师，大家好！我是第【　】号考生。

今天我说课的题目是《【课题名称】》，选自【教材版本】高中地理【必修/选择性必修】【册次】【章节】。

我将围绕“为什么教、教什么、怎样教、教得怎么样”四个问题，从教材与学情、教学目标、教学重难点、教学过程、板书设计及教学反思六个方面展开说课。

本课的设计理念是：以真实情境为载体，以地理问题为主线，以学生活动为中心，引导学生在证据分析和问题解决中发展地理核心素养。

二、教材与学情分析（约2分钟）

1. 教材分析

本节内容主要包括【知识点1】、【知识点2】和【知识点3】。

从教材体系看，本节课是在学生已经学习【前置知识】的基础上，进一步探究【本课核心内容】，并为后续学习【后续内容】奠定基础，具有承上启下的作用。

从课程标准看，本节课对应的要求是：“【摘录或准确概括课程标准】。”其中的行为动词是【描述/说明/解释/分析/评价/探究】，这意味着教学不能停留在知识记忆层面，而要引导学生借助【地图、景观图、统计图表、文字材料或实验数据】，认识【地理事物】的空间分布、形成过程及其人地关系。

从育人价值看，本节课不仅要帮助学生理解【核心地理原理】，还应引导学生认识【资源、环境、人口、发展】之间的关系，形成因地制宜、趋利避害和可持续发展的观念。

2. 学情分析

本课面向高中【年级】学生。

知识基础方面，学生已经掌握【已有知识】，能够进行基本的地图判读和材料信息提取。

能力基础方面，学生对【生活现象或区域案例】具有一定感性认识，但可能存在三个学习障碍：一是能够描述现象，却不能准确解释成因；二是能够罗列影响因素，却缺少因素之间的逻辑联系；三是能够记住一般规律，却不善于迁移到新的区域情境。

因此，本课通过由浅入深的问题链，将学生的感性认识转化为理性解释，帮助学生建立“获取信息—分析联系—解释过程—迁移应用”的地理思维路径。

三、教学目标与重难点（约1分30秒）

1. 教学目标

依据课程标准、教材内容和学生实际，我确定以下教学目标：

  1. 通过阅读【地图、图表或材料】，学生能够描述【地理事物】的【分布、变化或特征】，并用图中信息支持结论，发展区域认知。
  2. 通过分析【关键因素】之间的关系，学生能够解释【地理现象】的形成原因或演变过程，建立“【因素】—【过程】—【结果】”的逻辑链条，发展综合思维。
  3. 通过比较【区域甲】与【区域乙】，或者分析【典型案例】，学生能够归纳【地理规律或区位原则】，并迁移到新的区域问题中。
  4. 通过评价【人类活动或发展措施】的影响，学生能够从经济、社会和生态等角度提出合理建议，形成因地制宜和人地协调发展的观念。

以上目标中，【目标2】是教学重点；【目标3或目标4】既是教学难点，也是学生思维进阶的关键。

2. 重难点突破策略

教学重点通过“读图提取信息—合作分析证据—师生共同建模”落实；教学难点通过“典型案例对比—问题链追问—变式情境迁移”突破，避免由教师直接给出结论。

四、教法、学法与教学资源（约1分钟）

在教学方法上，我主要采用情境教学、问题导学、图表分析、合作探究和案例教学。

在学习方法上，引导学生运用读图析图法、比较归纳法、综合分析法和迁移应用法。

本课选用【地图、遥感影像、统计图、地理景观图、新闻材料或乡土地理案例】作为学习资源。信息技术服务于地理信息呈现和问题解决，而不是简单增加展示形式。

评价贯穿教学全过程。我将通过学生的地图标注、口头解释、学习任务单、因果关系图和迁移练习，及时判断目标达成情况，实现教学目标、学习活动与评价任务的一致。

五、教学过程（约8分钟）

我将本课设计为五个环节。

环节一：创设真实情境，提出核心问题（约1分钟）

首先，我展示【杭州乡土地理案例/新闻事件/地理景观/区域对比图片】，例如【具体情境】。

我提出问题：“【能够制造认知冲突的核心问题】？”

学生根据生活经验作出初步判断，不同判断之间形成认知冲突，由此引出本课主题《【课题名称】》。这样的导入既把教材知识与真实世界联系起来，也把学习内容转化为需要解决的地理问题。

本课的核心问题是：

【这一地理事物在哪里？为什么在那里？产生了什么影响？应当怎样发展？】

这一问题将贯穿整节课。

环节二：读图析图，认识地理特征（约1分30秒）

我提供【材料一：地图或统计图】，请学生完成三个任务：

  1. 从【位置、数量、空间格局、时间变化】等方面描述【地理事物】的特征；
  2. 在图中圈画或标注支持结论的信息；
  3. 用“总体—局部”或“时间—空间”的结构组织答案。

学生独立读图后进行同伴交流。我不急于公布答案，而是追问：“你的判断依据是什么？”“图中的哪些信息能够支持这一结论？”“是否存在特殊地区或异常现象？”

在学生回答的基础上，师生共同归纳：【地理事物】总体呈现【主要特征】，局部表现为【差异或特殊性】。

这一环节不仅要求学生说出结论，还要求学生提供证据，培养基于地理证据表达观点的习惯。评价标准是“特征准确、证据明确、表达有序”。

环节三：展开问题链，解释形成机制（约2分30秒）

这是本课的重点环节。

我提供【材料二：自然条件图】和【材料三：社会经济资料】，组织学生围绕以下问题链进行小组探究：

  1. 【地理现象】与【因素A】在空间分布上有什么关系？
  2. 【因素A】通过怎样的过程影响【地理现象】？
  3. 除了【因素A】，还有哪些自然或人文因素共同作用？
  4. 在不同时间、空间尺度下，主导因素是否发生变化？

各小组依据材料完成因果关系图，并选派代表汇报。

预计学生能够找到【地形、气候、水源、土壤、交通、市场、政策、科技、劳动力】等因素，但可能停留在简单罗列。对此，我进一步追问：“这些因素是彼此孤立的吗？”“哪一个是基础条件，哪一个是主导因素？”“因素之间存在怎样的相互作用？”

经过讨论，师生共同构建解释模型：

【背景条件】 → 【主导因素及作用过程】 → 【地理现象的形成或变化】 → 【区域差异或人地影响】

进一步概括为：【因素A】影响【中间过程】，进而导致【结果】；与此同时，【因素B】通过【作用方式】强化或削弱这一过程。

这一环节把零散的因素分析转化为有逻辑的机制解释，推动学生从“知道是什么”走向“理解为什么”，发展综合思维。

环节四：开展案例评价，解决真实问题（约2分钟）

为了促进知识迁移，我引入【区域案例或杭州乡土地理案例】，设置决策任务：

假如你是【规划者、企业负责人、当地居民或政府工作人员】，面对【真实问题】，你是否赞成【某项方案】？请说明理由并提出优化建议。

我为学生提供【经济数据、人口资料、生态环境资料和不同利益主体观点】。学生分组从四个角度进行评价：

  • 经济角度：【成本、效益、产业发展】；
  • 社会角度：【就业、公平、居民生活】；
  • 生态角度：【资源消耗、环境影响、生态安全】；
  • 区域角度：【当地条件、区域联系、发展阶段】。

在汇报过程中，我不以观点是否与预设一致作为唯一标准，而重点评价证据是否充分、推理是否合理、措施是否符合当地实际。

最终形成认识：地理决策需要立足区域条件，统筹经济、社会和生态效益，在权衡多方利益的基础上实现可持续发展。这一环节落实人地协调观，也体现地理学科服务现实决策的价值。

环节五：结构化总结，完成迁移检测（约1分钟）

课堂总结不由教师简单重复知识，而是请学生围绕三个问题进行回顾：本节课解释了什么地理现象？我们运用了哪些证据和方法？这一分析方法还能解决哪些地理问题？

师生共同形成学习路径：

特征描述 → 因素分析 → 机制解释 → 影响评价 → 决策建议

随后，我提供一个新的区域情境【新材料】，要求学生用一句话描述特征，用因果链解释原因，并提出一条因地制宜的发展建议。

这一迁移任务用于检测学生能否把本课形成的分析方法应用于陌生情境。如果学生只能复述原有案例，说明迁移目标尚未真正达成，我将在后续教学中增加变式训练。

六、板书设计（约40秒）

我的板书围绕核心问题进行结构化呈现：

                    《课题名称》

核心问题：【本课核心问题】

一、在哪里——特征
    【分布 / 变化 / 区域差异】

二、为什么——机制
    【背景条件】
         ↓
    【主导因素】→【作用过程】→【地理结果】
         ↑
    【其他因素】

三、怎么样——影响
    经济 + 社会 + 生态

四、怎么办——决策
    因地制宜 → 趋利避害 → 人地协调

这一板书既呈现本课的核心知识，也体现地理问题的分析路径，有利于学生形成结构化认知。

七、教学反思与结束语（约1分钟）

本课设计有三个特点。

第一，以真实问题统领教学。课堂不是按照教材标题逐段讲解，而是围绕核心问题组织学习活动，使知识学习服务于问题解决。

第二，以地理证据支撑思维发展。学生的每一个结论都要从地图、图表或材料中寻找依据，经历从信息提取到机制解释的过程。

第三，以迁移应用检验素养达成。课堂评价不仅关注学生是否记住结论，更关注学生能否运用所学方法解决新的区域问题。

本课也可能存在【材料数量较多、讨论时间不足、学生读图能力差异明显】等问题。实际教学中，我会根据课堂反馈适当精简材料，为不同学生提供分层任务和思维支架，并依据学生的学习成果及时调整教学节奏。

我的说课完毕，感谢各位评委老师的聆听，恳请批评指正。

杭州乡土地理情境参考

乡土地理案例应与课题自然贴合，不必每节课都使用。可以从以下方向选择：

  • 钱塘江涌潮、流域开发与防灾减灾；
  • 西湖水环境治理、城市湿地与生态修复；
  • 千岛湖水源保护与区域协调发展；
  • 杭州城市空间扩展、交通网络与功能分区；
  • 临安山核桃、龙井茶等特色农业的区位条件；
  • 杭州湾产业发展、港口交通与生态环境保护；
  • 梅雨、台风、寒潮、高温等天气过程及其影响。

使用乡土案例时，应明确它承担的教学功能：是导入核心问题、提供分析证据，还是用于迁移评价。不要只把“杭州元素”作为装饰。

忘词时的保底框架

如果现场一时忘词，可以回到以下四问：

  1. 在哪里？——描述地理事物的空间分布或变化特征。
  2. 为什么？——分析自然与人文因素，解释作用过程。
  3. 怎么样？——从不同尺度评价经济、社会和生态影响。
  4. 怎么办？——立足区域条件，提出因地制宜的措施。

最后补上评价闭环：“我将通过【学生作品或迁移任务】判断学生是否真正理解，并据此调整后续教学。”
